Seraflix 0.1 para macOS 13+, com UI compartilhada do stremio-sera, libmpv/VideoToolbox e servidor supervisionado.

Pacotes separados para Apple Silicon (M1 mínimo; M3 recomendado) e Intel. Assinatura ad hoc; não notarizado. Veja README para instalação, limites de HDR e testes realizados.

Esta release começa como draft. Publique somente depois de conferir os testes em Mac real e os arquivos de fontes correspondentes/avisos de todas as dependências GPL no modo `DEPS_MODE=source`.

Com chaves Sparkle configuradas, os assets `appcast-arm64.xml` e `appcast-x86_64.xml` são os feeds da atualização nativa via `releases/latest/download`. Conserve os ZIP referenciados pelo XML ao publicar a release.
